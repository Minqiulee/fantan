## 玩家端场次口令 + 场次绑定（第二轮）

### 设计

- **一个统一口令**（`PLAYER_SESSION_PASSWORD`，默认 `8888`），只管「选择 / 切换场次」这一个动作；不是一场一口令（理由与后续方案写在 README 待办第 10 条）。
- 口令只以 **scrypt(口令, 随机盐)** 存在进程内存：不落库、不下发、不进日志。`initPlayerPassword()` 启动时由环境变量重算。
- 验证通过 → 签发**绑定令牌** `ut = sid.exp.HMAC-SHA256(secret, sid.exp).slice(32)`，密钥随机生成存 `app_config.player_bind_secret`，所以**重启后玩家绑定仍有效**。
- 准入统一收口在 `playerSessionContext(sid, ut, staffToken)`：员工 token 直通（不受玩家口令约束）；玩家有令牌以令牌场次为准（改 sid → `session_locked`）；无令牌只在「唯一进行中场次」放行，否则 `session_need_unlock`。
- 客户端 `oe_bind = {sid, ut, exp}` 存 localStorage，不存口令；刷新/重开/多标签都复用；「切换场次」保留当前连接，选场次才弹口令，取消原样退回。

### 踩到的两个真 bug（都是测试逼出来的）

1. `unlockLockLeft()` 在「未锁定」时也会删掉失败计数 → 永远到不了 5 次。改为只在 `st.until` 非 0 时才做过期清理。
2. 取消口令弹层没退出「切换态」（`picking`），导致「切换场次」按钮被隐藏、无法再操作。取消统一 `picking=false; render()`。
3. 还顺手补了一个我自己引入的回归：员工端也走 `/api/state|stream`，多场时会被玩家口令拦住 → 员工侧改为带 `?token=` 放行。

## 结算归档 + 当日聚合 + 对账 CSV（第三轮）

### 设计要点

- 两张新表，与运行态彻底分离：`round_archive`（一轮一行：`session_id`+场次名/序号快照+轮次号+开奖数字+开奖单双+`locked_at`+`archived_at`+player_count/submitted_count，唯一键 `(session_id, round)`）、`round_archive_entry`（一人一行：`member_id`+预测单双/数字+submitted+两项命中+登记/提交时间，主键 `(archive_id, member_id)`）。
- **归档写在 `db.doSaveSession` 事务内**（`archiveRoundInTx`），锁定与归档原子完成；只 INSERT + `ON CONFLICT DO NOTHING`，重复保存不产生第二份、不改写既有行。
- **append-only 由触发器保证**：`archive_block_mutation()` 装在两张表的 `BEFORE UPDATE OR DELETE`（行级）与 `BEFORE TRUNCATE`（语句级），绕过应用层也改不了。已验证三种操作全部被拒。
- `reset` 只清 `round`/`player`；额外加了硬门：清空前若本轮已锁定则先 `await db.saveSession`，归档失败返回 409 `archive_write_failed`，避免抹掉唯一留痕。
- `/api/confirm` 现在 `await commitSession()`（`enqueueWrite` 改为返回 `{ok,error}` 不抛异常），失败返回 `ok:true, archived:false, warning:archive_write_failed`（锁定已生效，不能谎报失败诱导重按）。
- 时间口径：只认 `locked_at`，按固定偏移切自然日（`ARCHIVE_TZ_OFFSET_MIN` 默认 480=UTC+8，不走 IANA，无 DST 问题）。`dayBounds()` 严格校验日期（`2026-02-31` → 400）。
- 接口：`GET /api/archive/summary`、`GET /api/archive/export.csv?level=detail|member|round`（UTF-8 BOM+CRLF，列头顺序即契约，只许末尾追加）、`POST /api/archive-sync`（幂等补齐）。
- 启动 `backfillArchives()`：库里「已锁定但未归档」的轮次启动即补写（首次部署本功能时的回填），先 `archiveExists` 再写，避免每次启动无谓重写。
- `staff.html` 底部新增「当日结算」卡片：日期选择（默认今天）+ 场次/轮次/去重人数 + 三个 CSV 下载按钮；三语文案已补（`archiveTitle` 等 13 个 key）。
