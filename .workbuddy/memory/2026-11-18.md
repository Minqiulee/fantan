# 2026-11-18

## DB 连接串改为从 Fly secrets 拼接

- `db.js` 新增 `buildConnectionString()`：`PG_HOST` / `PG_USER` / `PG_PASS` 三者齐备时拼 `postgresql://...@PG_HOST:5432/postgres`（用户名密码 `encodeURIComponent` 转义）。
- 优先级：PG_* > `DATABASE_URL` / `PG_URL` > 本地默认 `postgres://postgres:postgres@localhost:5432/oddeven`。
- `server.js` 启动日志与错误提示、`DEPLOY.md`（部署步骤、环境变量表）同步更新。
- 端口 5432、库名 `postgres` 写死；如需 TLS 要在 Pool 配置加 `ssl`，Fly 内网同组织不需要。
- 本机 `fly` CLI 不可用：`~/.fly/perms.*` 删除报 operation not permitted，改用临时 config dir 后报 unauthorized，故未能在线核对 secrets 是否已存在。
